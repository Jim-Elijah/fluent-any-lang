# 常见问题（用户反馈摘要）

## 练习页能否「遮罩字幕」而不是整页隐藏？

可以。字幕栏按钮或 **`M`** 在三档之间循环：**不遮罩** → **只显示当前句** → **全部遮罩原文** → 不遮罩。列表与跟读、句库等行内按钮仍可用。遮罩用模糊挡住原文，行高与时间戳仍对齐；Echo 发音评分角标仍显示。

- **只显示当前句**：当前句原文清晰，其余句模糊。没有当前句时（还没进入任何一句，或已经播完最后一句），全部原文都模糊。句与句之间仍高亮上一句，那一句保持清晰。
- **全部遮罩原文**：每一句原文都模糊，包括当前句。

按 **`C`** 仍会隐藏整段字幕列表（遮罩档位保留，再显示后恢复）。有译文时 **`T`** 单独控制译文，遮罩不作用在译文上。

**设置 → 偏好与提示 → 遮罩原文** 决定下次进入练习时的默认。练习中的按钮和 `M` 只改这一次，不写回设置。

分期说明见 [`docs/plans/user-feedback-phased-plan.md`](plans/user-feedback-phased-plan.md)。

## 回声跟读能否跳过先听原音、直接开录？

**短期不打算支持。**

回声跟读（Echo）的设计是「先听再录」，参考台大史嘉琳教授的练法；跳过听句会模糊与影子跟读（Shadowing）的边界——若不需要先听，用 **影子跟读** 对当前句同步录，或在 **句库** 里自行控制播放再录更合适。

设置里可 **跳过录音倒计时**，或在 **3–10 秒** 间选择录音前等待（默认 3 秒；回声与影子跟读共用），与「跳过听原句」不是同一回事。

## 录音能否批量删除？

可以。在 **库 → 录音** 点 **「管理」**，多选后批量删除或导出。

## 字幕能否显示序号？

可以。练习页字幕列表在时间戳旁显示 **#序号**（与 Subtitle Segment 在轨内顺序一致，从 1 开始）。

## 同一句多条录音，能否只保留最好的一条？

回声模式每句可存多条，句旁 **「管理录音」** 可逐条删除。一键「仅保留本条」后续会评估。

## 跟读倒计时能否自定义秒数？

可以。在 **设置 → 偏好与提示** 中选择 **3–10 秒**，或开启 **跳过录音倒计时** 完全关闭等待。

## 录音库里难以看出是哪一句？

**库 → 录音** 列表会显示 **#句序号** 与 **原文摘要**（优先用录音时的句子快照，否则尽量对照当前字幕）。回声为单句序号；影子跟读跨多句时显示 **#起–止**（仅一句则只显示该句序号）。
